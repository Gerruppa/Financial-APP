# Valuation Snapshots are stored, unlike History

ADR-0002 recomputes History instead of storing it. The Dashboard's "change since the last refresh" (#115) stores a Valuation Snapshot anyway: Total's and each Account's value and Net Deposits, at most one a calendar day, written once History has been computed after a Successful Refresh. History's value for a day differs from what the Dashboard showed: it skips Manual Prices and does not exist while History is being computed. The comparison has to match the figure the user remembers seeing, so it uses the stored figure, not a recomputed one. The value is the Dashboard's (with Manual Prices, before tax). Net Deposits come from History, so there is a single definition of them. Because the snapshot stores them, a Transaction entered later with a date in the gap counts as a Deposit or Withdrawal in the gap rather than as market change. Snapshots are portfolio data: clearing the data removes them, and so does deleting their Account. A correction made later does not reach them, which is the trade-off ADR-0002 avoided for History and accepts here.
