# View Scope and period selector (#71, spec 5 and 6.1)

`domain/view_scope.py` (`parse_scope`/`scope_setting`, text `total` or an Account id in `app_settings` key `view_scope`, a gone Account falls back to Total; `scope_entries` sorts Accounts by History's value today with share and daily change, by name while History loads) and `ui/view_scope.py` (`ViewScope` with `on_change` listeners and `includes(transaction)`, `ScopeSwitcher` in the header: a menu drawn only while open (`scope-menu`, rows `scope-total`/`scope-<id>`), Total first, inactive Accounts behind "pokaż nieaktywne", "—" while History loads; `breadcrumbs` "Total › Account", its last step `breadcrumb-scope`). An Account scope is outlined in the Theme's accent (`k-scope-chosen` in `ui/theme.py`: the switcher button and `breadcrumb-scope`), and its menu row is lit with an accent bar and name (`k-scope-row` with `k-highlight`), so it is never mistaken for the Total in either Theme. Portfolio shows only the scope's card, Transakcje only its Transactions (Transfers to it included, `domain/view_scope.py` `in_scope`), and its export buttons export that list, the file named after the Account (`transakcje-<Account>.csv`). `domain/periods.py` (`PeriodPreset` 1M…5L, Od początku, Własny; `period_dates` clips to the first Transaction; YTD starts on 31.12 of the previous year; `months_before(day, months)` gives the same day that many months earlier, also used by the Instrument Card, #175; text in `app_settings` key `period`) and `ui/periods.py` (`PeriodChoice`, `period_selector`, preset buttons `period-<key>`), shown on the Dashboard and Wyniki.
