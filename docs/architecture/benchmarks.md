# Benchmarks (#91, spec 6.2)

`domain/benchmarks.py` `Benchmark` (`BenchmarkKind` CPI, INSTRUMENT, ACCOUNT; `offset` pp a year, `parse_offset`, `label`, `same_as`; `BenchmarkError`), each a daily `Growth` (`cpi_growth`, `price_growth` from `domain/portfolio_history.py` `pln_prices`, `account_growth` from `domain/metrics.py` `daily_returns`; `None` while the money waits as cash), and `compare` (the Portfolio row, then a `ComparisonRow` per benchmark: series over the period from the "from" day's value, difference, TWR, `short_history`); `DEFAULT_BENCHMARKS`. `persistence/benchmarks.py` (`list_benchmarks`, `add_benchmark` refusing a duplicate, `set_shown`, `delete_benchmark`, `ensure_default_benchmarks` once, app setting `BENCHMARKS_SEEDED`; table `benchmarks`, migration 0027; migration 0028 drops the first GPW defaults left on Stooq; deleting an Instrument or Account drops its benchmarks, `clear_portfolio` all). `sources/benchmarks.py` `benchmark_comparison` builds them from the caches; `PortfolioHistory.fetch` also fetches each benchmark Instrument from the first Transaction. `ui/benchmarks.py` `BenchmarksPage` (`/benchmarki`: `benchmark-row`, `benchmark-shown-<id>`, `benchmark-delete-<id>`, the `benchmark-add` form with `benchmark-kind`, `benchmark-instrument`, `benchmark-account`, `benchmark-offset`, `benchmark-add-button`; charts `chart-benchmarks-history`, `chart-benchmarks-values`; `benchmarks-pending` while History is computed); seeding or adding an Instrument starts a History fetch.
