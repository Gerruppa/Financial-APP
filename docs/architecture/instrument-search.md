# `domain/instrument_search.py`

The Instrument search (#25): `FoundListing` (one listing of a Search Result, `domain/header_search.py` `SearchResult` (#175), with its market, quote currency, the Source Symbols it gives and the ISIN searched for; Yahoo search returns no ISINs, so only an ISIN query fills one), the swappable `InstrumentSearch` protocol raising `InstrumentSearchError`, and `fill_empty(FormFields, result)`, which fills only the empty form fields (name, ISIN, quote currency, market, Source Symbols, Asset Class name, and for a `fund` result the domicile from the ISIN's country, `DOMICILES`, and the distribution policy from Acc/Dist words in its name), never overwriting what is entered; the dialog sets a class only while none is chosen, matched by name ignoring case (#59). `CombinedSearch` (#60) asks several searches side by side, marks each result's `source` and returns `FoundListings` whose `notes` say "<źródło> nie odpowiada"; all failing is an `InstrumentSearchError`. `sources/yahoo.py` `YahooSearch(fetch).search(query)` asks Yahoo search, plus one chart request per listing for its currency (in parallel); a `.WA` listing also gives the Bossa symbol; `quoteType` gives the Asset Class (EQUITY: Akcje polskie on `.WA`, else Akcje zagraniczne; CRYPTOCURRENCY, FUTURE, MUTUALFUND; ETF none); Yahoo matches an ISIN to one listing, so the listings sharing its full name are added. The Instrument dialog has the "Szukaj (ISIN, nazwa lub symbol)" field (prefilled with the name of an Instrument without Source Symbols; a new Instrument's default PLN counts as empty) and an "ISIN" field; `InstrumentDraft.isin` is optional and not unique (migration 0016). `InstrumentsSection.open_dialog(None, prefill=result)` fills the empty fields from a result as if it were chosen (the Instrument Card's "Dodaj jako instrument", see `header-search.md`, #175). `build_shell(..., search=...)` takes a test search, which the header search (#175) asks too. Tests run on `tests/fixtures/yahoo/search/`.
