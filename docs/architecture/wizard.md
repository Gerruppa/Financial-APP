# Step-by-step window (#268)

`ui/wizard.py` `Wizard(prefix, steps, width)` is the shell of every step-by-step window: a `ui.dialog` with a card marked `<prefix>-wizard`, a header "Krok N z M: <title>" marked `<prefix>-step-<n>`, the current step's body and a row of `<prefix>-back` ("Wstecz", from step 2), `<prefix>-close` ("Zamknij") and `<prefix>-next` ("Dalej", up to the last step, disabled until the step is ready). Each `WizardStep(title, body, done)` draws its body on every `render` and returns whether "Dalej" may follow; its optional `done` says whether the job the step points to is done. A window with such steps lists every step above the current one (`<prefix>-steps`, `_step_list`): a button per step `<prefix>-goto-<n>` going to it, a tick on a done one (also marked `<prefix>-done-<n>`) and an empty circle on one not done; the first-run window is the only one (#288). `open(step)` starts on step 1 unless told another, `go(n)` jumps to a step (e.g. after loading a file), `render` redraws the current one after a choice, `set_ready(flag)` enables or holds "Dalej" without a redraw (a field being typed in keeps the focus), `close` closes the window and keeps the step.

The user keeps the state the steps share (choices, loaded files) and makes the `Wizard` inside an element that outlives it, such as its card in Ustawienia: NiceGUI deletes a dialog with the element it was opened in (CLAUDE.md).

Users: the crypto import window (`ui/crypto_import.py`, prefix `crypto`), the XTB import window (`ui/xtb_import.py`, prefix `xtb`, see `xtb-import-reconciliation.md`), the first Recurring Rule (`ui/first_rule.py`, prefix `first-rule`, see `recurring-rules.md`), the first-run window (`ui/first_run.py`, prefix `first-run`, see `first-run.md`) and the price source help window (`ui/price_source_guide.py`, prefix `price-guide`, see `price-source-guide.md`). `tests/test_wizard.py` checks the header, "Wstecz", "Dalej" held until a step is ready, and the step list.
