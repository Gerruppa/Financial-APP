# Price source help window (#274)

`domain/price_source_guide.py` `advised_sources(instrument)` lists the Price Sources for an Instrument as `SourceAdvice` (`source`, `fits`, `in_order`, `help`): the sources that fit its Instrument Type and market first (a fund: analizy.pl, bankier.pl; crypto, a metal or an ETC: Yahoo; a stock, ETF or bond listed in Poland, i.e. on `POLISH_MARKETS` or in PLN without a market: Bossa, Yahoo, else Yahoo; any other type: whatever its class tries), then the other sources of its Asset Class's Fallback Order. `in_order` says whether that order tries the source at all, as only those Source Symbols are fetched. `SOURCE_HELP` gives each source's `SourceHelp` (`why`, `find`: where the symbol is found, `examples`), `MANUAL_HELP` the Manual Price alternative. Stooq is left out: it only serves History and its key section is hidden.

`ui/price_source_guide.py` `PriceSourceGuide(engine, sources, instrument, on_saved)` is a three-step `Wizard` (prefix `price-guide`, see `wizard.md`): 1. the advised sources, each with `price-guide-source-<source>` ("Wybierz") when in its class's order, else a note to add it in Klasy aktywów, and `price-guide-source-manual`; 2. for a source, how to find the symbol, the `price-guide-symbol` field, `price-guide-check` ("Sprawdź", `check_symbol` in `run.io_bound`, as in the Instrument dialog) and `price-guide-result`; "Dalej" follows only a Quote without a currency warning for the symbol still typed (`Wizard.set_ready`, so typing keeps the focus); for a Manual Price the `price-guide-price` field; 3. the summary and `price-guide-save`, which saves the checked Source Symbol (or the Manual Price) on the Instrument read anew, then `price-guide-saved`. Nothing fetched is saved: the price comes with the next refresh.

It opens from the `unpriced-guide` button of each row of Instrumenty bez wyceny (`unpriced-instruments.md`). Tests: `tests/test_price_source_guide_domain.py`, `tests/test_price_source_guide_ui.py`.
