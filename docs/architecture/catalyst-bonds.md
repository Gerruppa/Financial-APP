# Catalyst bonds (L-23, L-24, spec 4.2)

`domain/catalyst.py` (`BondFacts` nominal and accrued interest per bond in PLN, `bond_price`, `is_indexed` for `IZ_SERIES`, `IndexationDay` and `indexed_facts`: 1000 zł × the day's coefficient, rounded half up, the last day before it standing in up to `INDEXATION_STANDS_IN`, a week). `sources/catalyst.py` `CatalystFacts(fetch).of(symbol, day)` (`day` the Quote's) reads `parse_catalyst_listing` (the gpwcatalyst.pl "Instrumenty notowane" PLN table) and, for an IZ bond first, `parse_indexation` (the gov.pl "Współczynniki indeksacji" table), each page once a refresh (`new_refresh`), raising `PriceSourceError` without them. The sheet import reads the optional "Cena nominalna" column (`OPTIONAL_COLUMNS`; `SheetLine.unit_price` turns a percent into a price per bond when the nominal is over 1, the fingerprint unchanged). Migration 0025 gives "Obligacje skarbowe polskie" the order Bossa unless chosen and drops the Bossa Quotes of the Polish bond classes saved as percents. Tests run on `tests/fixtures/catalyst/` and `tests/fixtures/indexation/` and the bond listings in `tests/fixtures/bossa/_cat_bonds.json`.
