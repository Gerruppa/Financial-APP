# `sources/prices.py`

The `PriceSource` protocol and `refresh_prices(engine, sources, now)`: every Instrument with an open Position, its sources tried in order, the first Quote saved (`persistence/quotes.py` `save_quote`, one per Instrument and day, `latest_quotes`), returning a `RefreshResult` with the Instruments that failed in every source (reasons per source). Each refresh replaces the saved failures (`persistence/quotes.py` `save_refresh` and `load_refresh`, table `price_failures`, migration 0013; the time in `app_settings`); a source raising anything else than `PriceSourceError` counts as that source failing, so `last_refresh` gives the header's "Wyceny: <time>" status, red with the error count and clickable for the reasons, and the Portfolio marks those Instruments' Quotes stale. A refresh is a success (`RefreshResult.succeeded`; its time in `persistence/quotes.py` `last_successful_refresh`, app setting `prices_succeeded_at`) unless every Instrument fetched failed. The header's refresh button runs it through `run.io_bound`, and so does the start-up refresh (`app.py` passes `build_shell(..., refresh_at_start=True)`) when `domain/prices.py` `refresh_due` says the last success was before the most recent weekday `SESSION_CLOSE` (17:30, no holiday calendar); meanwhile the header says "Wyceny: odświeżanie…", and a reloaded window joins the running refresh (`_running_refreshes`, one per database) instead of starting another. `build_shell(engine, rates, sources, refresh_at_start, now)` takes test sources and a clock. `check_symbol` also passes on the Instrument Type a `TypingSource` (Yahoo, Bossa) tells of the symbol it quoted, as `SymbolCheck.instrument_type` (#198, `instrument-types.md`).
