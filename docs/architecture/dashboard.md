# Dashboard (#72, spec 5 and 6.1)

`domain/dashboard.py` `dashboard(transactions, accounts, instruments, prices, rates, history, account_id, period)` gives the View Scope's `Totals` (Net Deposits from History's last day, `None` while it is computed; value = PLN `cash` + `open_positions`, which hold the Positions and the foreign cash as in the sheet; `unrealized` and `realized` with the FX result unless the Account excludes it; Dividends, costs and `xirr`), an `AccountRow` per Account (an inactive one only while it holds something) and the `CurrencyShare`s (Positions by quote currency plus each currency's cash). XIRR ends at today's value as the Dashboard shows it (Manual Prices included), History supplying the days before. `domain/lots.py` `realized_results` gives each Account's realised result of Sells from the same FIFO replay as `open_positions`. It takes today's state from `sources/todays_view.py` (below) and the price status text from `sources/prices.py` `refresh_summary`, which the header shares. `ui/dashboard.py` `DashboardPage` draws the tiles (`total-<key>`), the price status (`dashboard-prices`), the Account table (`account-row`) and the exposure (`currency-row`) under the period selector, redrawn on a scope or period change, a save, a price refresh and when History is computed.
