# `sources/stooq.py`

`StooqSource(api_key, fetch).history(symbol, currency, first, last)`, daily closes from the Stooq CSV download (history and indices only, never current prices; the closes are taken as in the Instrument's quote currency). It needs the user's personal API key (`persistence/settings.py` `STOOQ_API_KEY` in `app_settings`, set in Ustawienia > Źródła wycen, `ui/price_sources.py`); `fetch_from_stooq` first answers Stooq's browser check (`answer_challenge`, a SHA-256 proof of work) and keeps the cookie. Tests run on `tests/fixtures/stooq/` (illustrative CSVs in the documented layout until a real response is saved). `sources/history.py` `QuoteHistory(engine).between(instrument_id, first, last)` is "an Instrument's Quotes in a date range" for Stage 4: days not fetched yet are fetched once from Yahoo, else analizy.pl (`AnalizySource.history`, the fund's whole valuation series filtered to the days, saved as `ANALIZY_HISTORY`, #101), else Stooq (#68; up to yesterday; today belongs to the price refresh) into the same `quotes` table, only on days without a Quote, then read from the cache (the last `UNSETTLED_DAYS` are asked again until Stooq has a Quote on or after them; `latest_quotes` never takes a Stooq, `YAHOO_HISTORY` or `ANALIZY_HISTORY` Quote, so history never values a Position; only PLN Instruments); an Instrument without a Stooq Source Symbol gives only its saved Quotes. `domain/history.py` `Cover` and `days_to_fetch` keep the fetched days one range (`persistence/history.py`, tables `quote_history`, `nbp_rate_history` and `nbp_history`, migration 0014); a new Stooq symbol, deleting the Instrument or clearing the portfolio drops its history. An index (e.g. WIG) is an Instrument with only a Stooq symbol. `NbpRates.history(currency, first, last)` gives the NBP Rates published in a range the same way (93-day pieces, from 2002-01-02, up to yesterday).
