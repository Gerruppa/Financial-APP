# Today's View state (#109)

`sources/todays_view.py` `todays_view(engine, rates)` loads once what the tabs draw today: `TodaysView` with the Transactions in entry order, Accounts, Instruments, `positions` (`open_positions`), `foreign` cash, PLN `cash` per Account, `prices` of each held Instrument (`sources/current_prices.py` `current_prices`, a Bond Series' from `bonds`) and the NBP `rates` known (`TodaysRates`, each held Instrument's and each Transaction's cash currency asked once), `pln_prices` and `account_value(account)`. `rates` is any `LatestRates` (`today()`, `latest(currency)`): `NbpRates`, or a test's fixed rates. `domain/account_value.py` `account_value` is the one definition of an Account's value and result (`AccountValue`: `cash`, `open_positions`, `unrealized`, `realized_fx`, `fx` shown even when the Account excludes it, `holds`; `result` is the Portfolio card's) and `is_listed` the rule hiding an inactive Account that holds nothing; the Portfolio's cards and the Dashboard's `AccountRow`s both use them. The Portfolio, Multi-asset, Obligacje (so it too asks for today's NBP Rates, cached per day) and `todays_dashboard` read the view; `tests/test_todays_view.py` runs it on in-memory SQLite with fixed rates and `tests/test_portfolio_parity.py` goes through it.
