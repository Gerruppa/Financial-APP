# Transakcje filters and sorting (L-27)

`domain/transaction_filters.py` `TransactionFilter` (`accounts`, a Transfer's target included; `types`; `instruments` with `NO_INSTRUMENT`; `amount_from`/`amount_to` on the Actual Amount; `date_from`/`date_to`; `comment` contained, ignoring case; `filters(column)`, `active`), `Sort` (`Column`, newest first by default; dates oldest first reverse the list, other columns keep it among equals) and `view`, plus `account_options`, `type_options`, `instrument_options` (the values listed). `ui/transactions.py` `_ColumnHeader` per column: `sort-<column>` (arrow `icon-right`) and `filter-<column>` (marker `filter-active` while set) opening a menu drawn only while open (`filter-all-<column>`, `filter-option-<column>-<value>`, `filter-<amount|date>-od`/`-do`, `filter-comment-text`); `clear-filters` ("wyczyść filtry"), `no-match`; `sources/export.py` `export_transactions(..., filters, sort)` exports what is listed. The list redraws in the background, so UI tests wait for it.
