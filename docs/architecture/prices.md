# `domain/prices.py`

`Quote`, `PriceSourceError` (Polish message), the Price Source keys (`YAHOO`, `BOSSA`, ...) and `SOURCE_NAMES`, and `sources_to_try(fallback_order, source_symbols)`: the Asset Class's Fallback Order, keeping only the sources the Instrument has a Source Symbol for (`symbol_in`: bankier.pl falls back to the Fund Code, the analizy.pl Source Symbol, #58; `without_fund_code_copy` drops a bankier.pl symbol equal to it, applied when the dialog opens and saves). Each Asset Class stores its own order (#41, `AssetClass.fallback_order`, copied onto `Instrument.fallback_order`; column `asset_classes.fallback_order`, comma-separated keys, migration 0018): `default_fallback_order(name)` gives the spec 4.1 defaults (any other class gets that of "Inne"), `validate_fallback_order` allows each of `FALLBACK_SOURCES` once (`FallbackOrderError`), `persistence/instruments.py` `set_fallback_order` saves it, `add_asset_class` gives a new class the current order of "Inne" (`new_class_fallback_order`) unless given one, and `clear_portfolio` restores the defaults. Ustawienia > Klasy aktywów shows each order and edits it in the class dialog (move, remove, add a source); `AssetClassesSection.on_changed` redraws the Instruments and the unpriced list. Instruments carry `source_symbols` (source key to symbol) in `InstrumentDraft`, saved in `source_symbols` (migration 0012).
