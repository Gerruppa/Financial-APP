# Version and installer (#99)

The one version number is `financial_app.__version__` (1.0.0), read by `pyproject.toml` (dynamic version), shown in the header (`app-logo`, then KAPITA and the version) and passed to the installer. `scripts/build_installer.ps1` runs PyInstaller on `packaging/kapita.spec` (a folder build `dist/KAPITA`, windowed; NiceGUI's package folder, the Alembic migrations, `ui/*.md` and `ui/assets` go as data files, since they are read as files) and then Inno Setup 6 on `packaging/kapita.iss` (per-user install in `%LOCALAPPDATA%\Programs\KAPITA`, Polish wizard, Start menu and optional desktop shortcut, a fixed `AppId` for upgrades; uninstalling leaves the data folder). `main.py` calls `multiprocessing.freeze_support()`, since NiceGUI opens the native window in a spawned copy of the frozen exe. The icons in `ui/assets` (`kapita.png`, `kapita.ico`) are cut from `packaging/kapita-logo.png` by `scripts/make_icons.py`.
