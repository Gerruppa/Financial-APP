# Version and installer (#99)

The one version number is `financial_app.__version__` (1.1.1), read by `pyproject.toml` (dynamic version), shown in the header (`app-logo`, then KAPITA and the version, which opens the changelog, #200) and passed to the installer. A release turns the changelog's "Nieopublikowane" into the new version's section (`changelog.md`). `scripts/build_installer.ps1` runs PyInstaller on `packaging/kapita.spec` (a folder build `dist/KAPITA`, windowed; NiceGUI's package folder, the Alembic migrations, `ui/*.md` and `ui/assets` go as data files, since they are read as files) and then Inno Setup 6 on `packaging/kapita.iss` (per-user install in `%LOCALAPPDATA%\Programs\KAPITA`, Polish wizard, Start menu and optional desktop shortcut, a fixed `AppId` for upgrades; uninstalling leaves the data folder). `main.py` calls `multiprocessing.freeze_support()`, since NiceGUI opens the native window in a spawned copy of the frozen exe. The icons in `ui/assets` (`kapita.png`, `kapita.ico`) are cut from `packaging/kapita-logo.png` by `scripts/make_icons.py`.

In-app update: `domain/app_update.py` `parse_latest_release` reads the GitHub API answer for `releases/latest` (tag `v<version>`, asset `KAPITA-<version>-setup.exe`, download address only on this project's Releases; `UpdateError` with a Polish message) and `newer_release` compares it with the running version. `sources/app_update.py` `UpdateSource` fetches it (`latest`), downloads the installer and checks its size (`download`) and starts it detached with `INSTALLER_ARGS` (`/SILENT /CLOSEAPPLICATIONS /NORESTART`, `install`); `can_install` is true only in the frozen app. `ui/app_update.py` `update_notice` (built under the version label when `build_shell(updates=...)` is given; the demo gives none) checks 3 s after the start, silently on any error, and shows `update-available`; its dialog (`update-dialog`) offers `update-install` (download, start the installer, `app.shutdown()`), `update-page` (the Releases page in the system browser) and `update-later`. `packaging/kapita.iss` has a second `[Run]` entry with `Check: WizardSilent` that starts the new version, since the wizard's entry is `skipifsilent`.
