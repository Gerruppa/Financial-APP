# `domain/instruments.py`

`AssetClass`, `asset_class_name` validation and `InstrumentDraft` (name, Asset Class id, quote currency, market, optional Manual Price, `quantity_decimals` 0–`MAX_QUANTITY_DECIMALS` (8), default 0, which only rounds the quantity the transaction dialog proposes (#120; migration 0030 fills it from the most decimals an Instrument's Transactions use, 8 for the "Kryptowaluty" class; dialog field `instrument-quantity-decimals`)), raising `InstrumentError`. `persistence/instruments.py` saves both (`list_asset_classes`, `add_asset_class`, `rename_asset_class`, `list_instruments`, `add_instrument`, `update_instrument`). A fund's optional `ter_percent` (0 to under 100), `distribution_policy` (`DistributionPolicy`: Akumulacja / Dystrybucja) and `domicile` (#42, migration 0017) are entered in the Instrument dialog and shown, through `ui/fund_details.py`, in the Instrumenty list and above a clicked Position's Lots in the Portfolio. Instruments point at their Asset Class by id, so a rename shows everywhere; migration 0004 seeds the sheet's 12 classes. `domain/currencies.py` holds the shared currency-code check, `NbpRate` and `MissingNbpRateError`.
