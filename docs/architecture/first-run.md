# First-run window (#270)

`ui/first_run.py` `FirstRunWizard(engine, open_settings, add_transaction)` is a five-step window on the shared `ui/wizard.py` (prefix `first-run`): Witaj w KAPITA (what the app does, that the data stays on this computer), Konta (the Account Types, their taxes and the IKE/IKZE/OIPE Contribution Limits; the Accounts so far in `first-run-accounts` and `first-run-add-account`, which opens `ui/accounts.py` `open_account_dialog` and redraws the step), Historia transakcji (`first-run-import` goes to Ustawienia > Import with the XTB and crypto imports, `first-run-add-transaction` opens the Transaction form), Wyceny (the Price Sources by kind, no key needed; `first-run-instruments` goes to Ustawienia > Instrumenty) and Gotowe (where the tabs are, and how to reopen it, `first-run-done`). Only the Konta step saves data; the others close the window and go to the screen that does the job. The Stooq key is not offered: its section (`ui/price_sources.py`) is not in Ustawienia, as History runs on Yahoo.

`build_shell(offer_first_run=True)` (passed by `app.py`; tests leave it off, so their empty databases open no window) calls `open_if_new`: the window opens while `list_accounts` is empty and `persistence/settings.py` `FIRST_RUN_DISMISSED` (`ui.first_run_dismissed`, kept on clearing the data) is unset. However the window closes (Zamknij, a step's button, Esc), its `on_value_change` saves the key, so it never opens by itself again. Ustawienia > Konta's `first-run-open` ("Pierwsze kroki", `AccountsSection(open_first_run=)`) reopens it at any time, with `AccountsSection.changed` as `on_accounts_changed`, so an Account added there shows in Konta. The window is made in `ui.context.client.content`, so it outlives the tab it opened on.

Going to a section: `ui/settings.py` `SettingsSection` (one per shell, `build_settings_page(section=)`) holds the section the next Ustawienia page starts on (`key`, consumed when drawn) and the page's `ui.tabs`; `show(key)` switches the tabs of the page on screen, or keeps the key for the page `ui.navigate.to` draws next. Tests: `tests/test_first_run_ui.py`.
