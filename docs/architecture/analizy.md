# `sources/analizy.py`

`AnalizySource(fetch).quote(symbol, currency)`, funds and PPK from the undocumented analizy.pl API (`/api/quotation/fio/<ID>`): the newest valuation of the first series with its day (often D-1), in the fund's currency (a mismatch is a `PriceSourceError`). `sources/bankier.py`: `BankierSource`, its fallback, reads the price and day from the header (`data-symbol="<ID>"`) of the bankier.pl fund page, then the PPK page. Tests run on `tests/fixtures/analizy/` and trimmed pages in `tests/fixtures/bankier/`. `AnalizySearch(fetch)` (#60) finds FIO, SFIO, PPK and FZG funds through the site's search API (exact `fields` parameter), names without markup or the former name, currency from each fund's quotation, PPK in Multi-asset; tests on `tests/fixtures/analizy/search/`. The Instrument dialog has "Symbol Yahoo", "Symbol Bossa", "Kod funduszu" (the analizy.pl field, standing where the first of analizy.pl and bankier.pl is in the class's order; its "Sprawdź" checks both) and "Symbol bankier.pl (gdy inny niż kod funduszu)", always under "Więcej źródeł" (#57: the chosen Asset Class's Fallback Order sources first, in that order, marker `class-sources`; the rest in the collapsed "Więcej źródeł (N wypełnione)", `more-sources`, still saved; Stooq in "Historia notowań (Stooq)", `stooq-history`; no class or an empty order shows a note where the price comes from; a class change moves the same fields, so values and checks stay); `build_shell` defaults to all four sources and to `CombinedSearch` of Yahoo and analizy.pl. Each of those fields has a "Sprawdź" button (#39): `sources/prices.py` `check_symbol(source, symbol, currency)` fetches one Quote anew (`new_refresh` first) and returns a `SymbolCheck` (the Quote, a `warning` or an `error`), shown under the field as "<price> <currency> · <day>"; nothing is saved, so the Instrument saves whatever the check found. A source quoting in another currency than the Instrument's raises `domain/prices.py` `CurrencyMismatchError` (a `PriceSourceError` carrying the source's own Quote), which the check shows as a warning beside that price. Its search results are of the Fundusz Instrument Type (#198).
