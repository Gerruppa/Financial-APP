# Early Redemption (L-5, spec 3.4.1, ADR-0007)

A Sell may name its Lot (`TransactionDraft.lot_id`, the id of the Transaction that opened it; column `transactions.lot_id`, migration 0024) and carry the tax withheld at redemption in `withholding_tax` (PLN only; the Actual Amount is quantity × price less the commission, the fee, and that tax, the Tax Amount before the tax; `profit_sources` counts it under taxes). `domain/lots.py` `Lot.opened_by` (a saved Transaction's id, not compared) names each Lot; `_replay` takes a named Sell's units from that Lot alone (`LotNotHeldError` when it is gone, `InsufficientQuantityError` when short), a Sell without one stays FIFO; `open_lots(transactions, account, instrument, day, edited_id)` (entry order) lists what a Sell that day may name. `TransactionDraft.with_id` gives the saved form, so `_check_coverage` keeps an edited Buy's name. `domain/bond_redemption.py` `early_redemption(price, lot, quantity, tax_rate)` gives the `EarlyRedemption` prefill (one bond's gross value, the fee and tax for all the bonds, `net`). The "+" dialog shows `transaction-lot` (oldest by default) for a Sell of a Bond Series, prefills quantity, price, commission and `transaction-withholding-tax` ("Podatek pobrany"), overwriting only what it set itself, and shows "Wypłata netto"; the Transakcje list shows "opłata · podatek".
