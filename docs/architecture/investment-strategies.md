# Investment Strategies (#76, spec 5 and 6.1)

`domain/strategy.py` `Strategy` (Account id or `None` for Total; `class_targets` by Asset Class id as `ClassTarget` percent and ±pp `band`, default `DEFAULT_BAND` 5; `instrument_targets` percent of the class by Instrument id; `StrategyError`) and `strategy_view(strategy, asset_classes, instruments, classes, holdings, planned)`: `ClassRow`s in the Asset Class order (share, `difference` in pp, `to_target` with sales, `from_deposit`, `status` `BandStatus` green within the band, yellow up to 2×, red beyond; `InstrumentRow`s, `split_blocked` while Instrument Targets do not sum to 100), `rebalancing_deposit` (`None` while an untargeted class holds value) and `targets_sum`; `water_fill` splits the Planned Deposit, `deposit_accounts` names the Accounts for Total's split. `domain/dashboard.py` gives the scope's `holdings` (value by class name and Instrument id) and `account_classes`. `persistence/strategies.py` (`list_strategies`, `save_strategy`, `delete_strategy`; tables `strategies`, `class_targets`, `instrument_targets`, migration 0021); a class with a target cannot be deleted, deleting an Instrument drops its targets, `clear_portfolio` removes them. `sources/dashboard.py` `todays_dashboard` computes today's Dashboard of a scope from `todays_view` for the Dashboard, the tab and the notice. `ui/strategy.py`: `StrategyPage` (the Strategie inwestycyjne tab: `edit-targets` dialog with `target-<class id>`/`band-<class id>`, `edit-instrument-targets-<class id>` dialog with `instrument-target-<id>` for the class's `InstrumentRow`s (held or targeted, in the tab's order, largest first) and an `add-instrument-target` select adding the class's other catalog Instruments, `create-strategy`/`delete-strategy` in an Account scope, rows `strategy-row band-<status>` coloured by the class `k-band-<status>` (`ui/theme.py` `BAND_COLOURS` per Theme), `deposit-<class id>`, `accounts-<class id>`, `instrument-row` on the class rows' grid (both kinds of row `k-hover`, lit under the cursor): value, share within the class, target and part of the deposit under Wartość, Udział, Cel and Z wpłaty), `strategy_section` (the Dashboard's `dashboard-strategy` card with `strategy-details`), the `planned-deposit` field shared through `PlannedDeposit`, and `out_of_band_notice`, shown after a price refresh. The allocation chart adds a "Cel" series.
