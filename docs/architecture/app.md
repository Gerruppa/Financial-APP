# `app.py`

Entry point, also used by `main.py`, by the console-less `kapita-gui.exe` that the desktop shortcut starts (`scripts/create_desktop_shortcut.ps1`) and by the installed `KAPITA.exe`. It first moves a pre-1.0 `%LOCALAPPDATA%\FinancialApp` folder to `%LOCALAPPDATA%\KAPITA` (`persistence/paths.py` `adopt_legacy_data_dir`, only when the new folder does not exist and `FINANCIAL_APP_DATA_DIR` is unset; when the folder is in use, a Windows message box `LEGACY_MOVE_FAILED` asks to close the old version and the start stops, so the next start tries again). Without a console, stdout/stderr go to `paths.log_path()`; a stream pywebview swapped for `os.devnull` on import counts as missing. The window's title and icon are `ui/shell.py` `APP_TITLE` ("KAPITA") and `APP_ICON`. After that it opens the startup log (`startup.log`) and `ui.run` builds `root`: with no User signed in the login screen (`users.md`), afterwards `ui/shell.py` `build_shell` on the User's engine. `Session` holds who is signed in: `open(pseudonym, folder)` moves the log to that User's folder, backs the database up (before migrating) and runs the migrations; `close()` stops the User's background work and disposes the engine. `--demo` opens the made-up User "Demo" (the demo folder itself) at once and offers no switching. `--browser` and `--demo` open the UI in a browser instead, the latter on made-up data: see `demo-mode.md`.
