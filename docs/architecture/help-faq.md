# Pomoc / FAQ (#156)

`domain/faq.py` `parse_faq(text)` reads the FAQ's Markdown into `Section`s (`# Title`) of `Question`s (`## Question? {#slug}`, an optional `Przejdź do: /path` line right below naming the tab its answer is about, then the Markdown answer up to the next heading); a question before any section, without a slug, with a repeated slug or an empty answer, or a section without questions raises `FaqError` (Polish). `matching(sections, query)` keeps the questions whose title or answer contains the text, ignoring case and Polish letters. The text is `ui/faq.md`, shipped as package data (`pyproject.toml`), so answers grow without code changes; `tests/test_help_ui.py` checks it covers the agreed topics and links only to tabs. `ui/help.py` `build_help_page(tab_labels)` is the last tab (`HELP_PATH` `/pomoc`, icon `help`, always shown, no "+"; `help`, `faq-search`, an `ui.expansion` `faq-<slug>` per question with its `ui.markdown` answer and `faq-<slug>-go` "Przejdź do: <tab>" navigating to the path, also to a tab hidden in Wygląd i widoczność; sections left without a match hide, `faq-no-match`). It draws nothing from the database, so it declares no `CHANGES`. The Dashboard shows `first-steps` (button `first-steps-help`) while no Transaction is saved.
