# `sources/bossa.py`

`BossaSource(fetch, bonds).quote(symbol, "PLN")` from the Bossa JSON API (GPW shares, NewConnect, ETF and Catalyst bonds, searched in that order): one request per category per refresh (`refresh_prices` calls each source's `new_refresh` first, and a failed category is not asked again in that refresh); a listing without a positive price or a day is skipped; a Catalyst bond's percent of nominal becomes a price per bond (`domain/catalyst.py` `bond_price`: percent × nominal / 100 + accrued interest, from `bonds`, a `BondFactsSource`, by default `sources/catalyst.py` `CatalystFacts`), and without its nominal it gets no Quote; a symbol is Bossa's short (`CDR`) or full (`CDPROJEKT`) one, the reference price stands in when there was no trade, and a non-PLN Instrument is a `CurrencyMismatchError` (the symbol is looked up first, so the check can show its PLN Quote). Tests run on trimmed responses in `tests/fixtures/bossa/`. `instrument_type_of(symbol)` tells the Instrument Type of the category a symbol was quoted in this refresh (#198, `instrument-types.md`).
