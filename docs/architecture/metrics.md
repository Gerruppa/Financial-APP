# `domain/metrics.py` (#69, spec 6.1)

On a `daily_history` list, a period (`first`, `last`, clipped to the History) and a scope (`account_id`, `None` for Total), `xirr` (the "from" day's value paid in, each day's change in Net Deposits as a flow, the "to" value paid out; `None` without a rate), `twr` (daily (V_D − F_D) / V_{D−1} − 1 chained, flows at the end of the day, a day after a zero value skipped), `drawdowns` (per day, on the TWR), `max_drawdown` (`MaxDrawdown`: depth, peak, trough, `recovered_on`, from which Wyniki counts the recovery days) and `volatility` (sample deviation of weekday TWR returns × √252). Returns are fractions, not percent. `daily_change` (V_today − V_yesterday − today's flows) feeds the View Scope switcher; the Dashboard charts use `drawdowns` and `xirr_to_each`, Wyniki the rest (`domain/results.py`).
