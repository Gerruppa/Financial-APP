# Valuation Snapshots (#115, ADR-0008)

`domain/valuation_snapshots.py` (`Figures` value and Net Deposits, `ValuationSnapshot`, `snapshot_figures` (each Account's value today with History's last day's `account_net_deposits`, Total the Accounts' sum with `net_deposits`), `change_since` giving a `SnapshotChange`: `total` = `market` + `net_deposits`, `percent` the market change as a fraction of the snapshot's value, `None` at 0). `persistence/valuation_snapshots.py` (`save_snapshot` replacing that day's, `snapshot_before(engine, day, account_id)` the newest of an earlier day; table `valuation_snapshots`, migration 0031, `OnClear.DELETE`, deleted with its Account by `delete_account`). `sources/valuation_snapshots.py` `take_snapshot` (values from `todays_view`, so with Manual Prices and before tax) and `change_since_snapshot` (`None` while History is computed). The shell marks a snapshot due after a Successful Refresh (`RefreshResult.succeeded`) and takes it in `load_history` once History computed since then is there (`PortfolioHistory.computed`, never an overtaken computation's days). `ui/dashboard.py` draws the line under the tiles (`since-snapshot`, "Od 09.10, 18:02: +1 234 zł (+2,1 %), w tym rynek …, wpłaty netto …"), unaffected by "Po podatku".
