# Theme: Jasny and Golden (#174)

`domain/themes.py` `Theme` (`LIGHT` "jasny", `GOLDEN` "golden", `label` Jasny/Golden) and `parse_theme` (nothing or unknown text is Jasny); it is kept in `app_settings` key `ui.theme` (`persistence/settings.py` `UI_THEME`, one for every View Scope, kept by clearing the data; no migration). `ui/theme.py` `ThemeChoice(engine)` is the window's Theme (`choose(theme)` saves it and calls its `on_change` listeners; the shell's listener reloads the window, so every tab and chart is built again in it). `apply_theme(theme)` styles the page being built: `CSS` (colour variables `--k-*` on `body.theme-jasny`/`body.theme-golden`, the `k-` classes `k-header`, `k-side`, `k-menu-item`/`k-active`, `k-muted`, `k-hero`, `k-accent`, `k-highlight`, `k-icon`; every `q-card` gets the border and radius; Golden draws gold mountains, an inline SVG, behind the header and at the foot of the menu), Quasar's colours (`primary`; custom `ink` for the header's text, `side`/`side-active` for the menu, `attention` for pending Drafts, `negative`) and dark mode for Golden. A page names these tokens, never a colour (`color=primary`, not `indigo`). ECharts draws on canvas, so every chart goes through `ui/theme.py` `echart(options)`, which passes `chart_theme()`: none for Jasny, a dark theme with gold first for Golden; `current_theme()` reads the Theme the page put in its client's storage (Jasny outside a page). `LINE_COLOURS` colour the Dashboard's main chart and the sparklines, `LABEL_COLOURS` the waterfall's change labels. `theme_section(choice)` is the toggle in Wygląd i widoczność (`ui-theme`); the header's `theme-toggle` switches to the other Theme. The design was chosen with a prototype on branch `prototype/dashboard-redesign`.
