# Discreet mode

The header's eye button `discreet-toggle` (`ui/discreet.py` `build_discreet_button`, left of "Wesprzyj"; the icon is `visibility_off` while the mode is on) blurs every amount, for working with someone looking on. `DiscreetChoice(engine)` holds `on` and `toggle()` saves it in `app_settings` key `ui.discreet` (`persistence/settings.py` `UI_DISCREET`, `1` or `0`, one for every View Scope, kept by clearing the data like `ui.theme`; no migration). `apply_discreet(choice)` (called by `ui/shell.py` after `apply_theme`) adds the CSS and a script, and puts the class `k-discreet` on `body` when the mode is on; the button toggles that class with `ui.run_javascript`, so switching needs no reload.

Amounts are plain text in labels, tables and cards, so the script walks the text nodes and adds the class `k-money` to the element holding one that matches `MONEY_PATTERN` (a number with a decimal comma and "zł" or a currency code, exactly what `domain/formatting.py` writes: amounts, unit prices and rates; percents, dates and quantities stay readable). It only adds a class, never replaces a node, so NiceGUI's redraws keep working; a `MutationObserver` marks what a redraw brings. `body.k-discreet .k-money` and `.nicegui-echart` (charts draw on canvas) get `filter: blur`, and hovering one shows it. `tests/test_discreet.py` checks the pattern against `format_pln`, `format_amount` and `format_rate`, the remembered choice and the button; the blur itself needs a browser: `scripts/screenshot.py --discreet` shoots a tab with the mode on.

The "Wesprzyj" button next to it drops its name below 1440 px (`gt-md`), so the header stays in one line at the native window's width.
