# Passive-income calendar (#93, spec 6.2)

`domain/passive_income.py` (`IncomeKind`, `IncomeItem`, `received_income`, `forecast_coupons` from the coupon Drafts, `income_by_month` giving `MonthIncome` with `progress(goal)`, `monthly_average` over the 12 whole months before today's, `parse_income_goal`); `sources/passive_income.py` `income_items`; app setting `PASSIVE_INCOME_GOAL`. `ui/passive_income.py` `PassiveIncomePage` (`/dochod-pasywny`: `income-year-prev`/`-next`, `income-year`, `income-goal` with `income-goal-save`, tiles `income-<key>`, rows `income-month` (amounts right-aligned under their headers; the Cel column only with a goal set), `chart-passive-income`, `income-forecast-row`). `ui/charts.py` `pln_lines_chart` and `pln_bars_chart` draw these tabs' charts (`pln_bars_chart` names every category, slanted when more than six run long).
