# Saying of the day (#178)

`domain/sayings.py` `Saying` (`text`, `work`, `author`: `WALASZEK` for Kapitan Bomba, Egzorcysta and Bogdan Boner: Egzorcysta, `None` for Chłopaki z baraków, whose signature then names the work alone), the fixed list `SAYINGS` (lines found in published collections of the shows' quotes, the Egzorcysta ones from the Egzorcysta fandom wiki's Bogdan Boner page; the works take turns) and `saying_of_the_day(day)`: the list cycles by the day's ordinal, so a saying stays all day and a redraw does not swap it. Named "saying", not "quote", because a Quote is an Instrument's price. `ui/sayings.py` `menu_saying(day)` is the line at the foot of the shell's menu (`menu-saying`); the Dashboard has none, so the saying is not shown twice. The element `sayings` ("Cytat dnia", group Menu) in Wygląd i widoczność hides it; Podstawowy shows it, so a Podstawowy saved before it still reads as Podstawowy.
